# Casulo de Yveltal

> Conteúdo adicionado na versão **8.0** do Legendary Monuments.

## Visão geral

Yveltal é libertado de um **Casulo de Yveltal** (Yveltal Cocoon) — uma estrutura-bloco própria. Para acordá-lo você alimenta o casulo com **Potes de Alma** (Soul Jar), o mesmo recurso sombrio ligado ao sistema de Marshadow (veja o arquivo de Marshadow).

## Como invocar Yveltal

1. Encontre a estrutura do **Casulo de Yveltal**.
2. Reúna **16 Potes de Alma** (Soul Jar).
3. Use os potes no casulo, um a um. O bloco mostra o progresso: *"X/16 soul jars offered"*.
4. Ao completar os 16, Yveltal desperta: *"Yveltal has awakened, the harbinger of destruction!"* (Yveltal despertou, o arauto da destruição!).

Se aparecer Shiny (2%), a mensagem muda para *"Shiny Yveltal has awakened, the harbinger of destruction!"*.

## Quest no Arc Phone

- **"The Dark Wings Descend"** (As Asas Sombrias Descem) — Yveltal.

> Dica: como tanto o Casulo de Yveltal quanto Marshadow consomem Potes de Alma, planeje a coleta — veja o sistema de **Caldeirão das Sombras / Shadow Ichor** no arquivo de Marshadow para entender de onde vêm os Potes de Alma.

# Tipos e Features de Raid

## Tipos de Raid

Cada Cristal de Raid tem um **tipo** associado, que determina a cor/aparência do cristal e os Pokémon que podem aparecer nele. São 20 tipos no total:

| Tipo      | Visual       |
|-----------|-------------|
| Normal    | Cinza        |
| Lutador   | Marrom/vermelho |
| Voador    | Azul claro   |
| Venenoso  | Roxo         |
| Terra     | Marrom       |
| Pedra     | Cinza escuro |
| Inseto    | Verde limão  |
| Fantasma  | Roxo escuro  |
| Metálico  | Prata        |
| Fogo      | Vermelho/laranja |
| Água      | Azul         |
| Planta    | Verde        |
| Elétrico  | Amarelo      |
| Psíquico  | Rosa         |
| Gelo      | Ciano        |
| Dragão    | Índigo       |
| Sombrio   | Preto        |
| Fada      | Rosa claro   |
| Estelar   | Branco/prateado (especial, endgame) |

O tipo do cristal não significa que o Pokémon-chefe terá necessariamente esse tipo — ele define qual grupo de chefes pode aparecer naquele cristal conforme a configuração do servidor/mod.

## Features de Raid

Além do tier e do tipo, algumas raids têm uma **feature** especial que altera a forma do Pokémon-chefe. Features são visuais e mecânicas — o chefe aparece em uma forma mais poderosa.

### Regular (DEFAULT)
- O Pokémon-chefe aparece em sua forma normal.
- Nenhuma mecânica especial além do multiplicador de HP do tier.

### Mega Evolução (MEGA / MEGA X / MEGA Y)
- O chefe aparece em sua forma Mega Evoluída.
- Requer o mod **Mega Showdown** (≥1.6.2) instalado para funcionar.
- Conquista relacionada: **"Transbordando poder"** (derrote uma raid Mega).

### Terastalização (TERA)
- O chefe usa Terastalização, podendo mudar de tipo durante a batalha.
- Ao vencer um raid TERA, você recebe **Tera Shards** como recompensa extra.
  - Tier 1: 1–3 Tera Shards
  - Tier 2: 1–3 Tera Shards
  - Tier 3: 2–5 Tera Shards
  - Tier 5: 5–10 Tera Shards
  - Tier 7: até 30 Tera Shards
- Conquista relacionada: **"O tesouro da área zero"** (derrote uma raid Tera).

### Dynamax (DYNAMAX)
- O chefe aparece em forma Dynamax, com HP aumentado.
- Ao vencer um raid DYNAMAX, você recebe **Max Mushrooms** como recompensa extra.
  - Tier 1–2: 0–1 Max Mushroom
  - Tier 3: 0–2 Max Mushrooms
  - Tier 5: 1–2 Max Mushrooms
  - Tier 7: 3 Max Mushrooms
- Conquista relacionada: **"Uma aventura Dynamax"** (derrote uma raid Dynamax).

### Gigantamax (GIGANTAMAX)
- Variante especial de Dynamax com forma visual única.
- Mesma mecânica do Dynamax em termos de recompensas.

### Eternamax (ETERNAMAX)
- Forma permanente de Gigantamax (usada por Eternatus).
- A mais poderosa das formas especiais.

### Primal (PRIMAL)
- Forma de Reversão Primal (usada por Kyogre e Groudon).
- Aparece como uma forma avançada e poderosa.

## Como saber a Feature de um Cristal

Ao apontar para o Cristal de Raid com o mod Jade ou WTHIT instalado, as informações do cristal — incluindo tier, tipo e feature — são exibidas na tela. Sem esses mods, você descobre ao iniciar a batalha e ver o Pokémon aparecer.
